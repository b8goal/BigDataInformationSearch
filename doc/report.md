## 1. 서론
- 과제 목표
  1. Local 또는 클라우드 환경에 Docker 기반의 ElasticSearch + Kibana를 설치한다.
  2. 30개 이상의 한국어 중심 문서/웹/블로그뉴스 등으로 데이터셋을 구성한다.
  3. 검색 엔진을 구축한다.

## 2. 검색 엔진 구축 환경 설정
- ElasticSearch 및 Kibana 설치
  - Docker를 사용하여 ElasticSearch 및 Kibana를 설치한 과정을 서술한다.
  - Docker Compose 파일 또는 실행 명령어 등 구체적인 설정 방법을 기술한다.
  - 설치 과정 중 발생한 문제점 및 해결 방안을 포함한다.
- 설치 환경
  - 환경: Local(macOS)
  - 도구: Docker, Docker compose
  - 목적: Elasticsearch + Kibana (한국어 형태소 분석, 대량 색인, 검색 실험)
  - 설치 대상: Elasticsearch 8.11.4, Kibana 8.11.4 (한국어 형태소 분석용 Nori 플러그인 포함)
- 환경 구축 방법 (ElasticSearch 및 Kibana 설치)
  - 첨부 파일의 docker-compose.yml을 참고하여 아래 명령어를 실행한다.
    ```bash
    cd deploy
    docker-compose up -d
    ```

- 설치 과정 중 발생한 문제점 및 해결 방안
  - 커스텀 이미지/플러그인 설치
    - 문제: Nori 등 한국어 형태소 분석 플러그인 설치 필요
    - 해결: Dockerfile에서 플러그인 설치 후 build, 또는 컨테이너 내부에서 직접 설치
  - 보안/토큰/비밀번호 문제
    - 문제: 기본 설정에서 서비스 토큰/비밀번호 요구, Python 연동 시 인증 오류
    - 해결: xpack.security.enabled=false로 보안 비활성화, 필요시 토큰/비밀번호 환경변수 주석 해제
  - 메모리 부족/컨테이너 실행 실패
    - 문제: ES_JAVA_OPTS 미설정 시 컨테이너가 메모리 부족으로 종료됨
    - 해결: "ES_JAVA_OPTS=-Xms1g -Xmx1g"로 메모리 명시
  - Kibana-ES 연결 오류
    - 문제: Kibana에서 Elasticsearch 연결 실패
    - 해결: ELASTICSEARCH_HOSTS=http://elasticsearch:9200로 내부 네트워크 연결 명시
  - 데이터 영속화/권한 문제
    - 문제: 컨테이너 재시작 시 데이터 손실
    - 해결: volumes 설정으로 데이터 영속화

## 6. 검색 엔진 개발 (Python Client 활용)
- Python Client 연동
    ```python
    from elasticsearch import Elasticsearch, helpers

    es = Elasticsearch("http://localhost:9200")

    # 데이터 색인을 위한 설정
    index_name = "korean_news"

    # bulk 색인을 위한 데이터 생성
    def generate_actions(documents):
        for i, doc in enumerate(documents):
            yield {
                "_index": index_name,
                "_id": i + 1,
                "_source": doc
            }

    # 데이터 색인 실행
    try:
        success, failed = helpers.bulk(es, generate_actions(docs), stats_only=True)
        print(f"성공적으로 색인된 문서 수: {success}")
        if failed:
            print(f"색인 실패한 문서 수: {failed}")
    except Exception as e:
        print(f"Bulk 색인 중 오류 발생: {e}")
    ```
    - 위 코드는 ElasticSearch Python Client를 사용하여 데이터를 색인하는 방법을 보여준다

- Kibana를 이용한 Bulk 텍스트 처리 및 색인
  - Kibana를 활용하여 대량의 텍스트 데이터를 처리하고 ElasticSearch에 색인한 과정 (참조 파일: `search_with_bm25.py`)
    ```python
    from elasticsearch import Elasticsearch

    es = Elasticsearch("http://localhost:9200")
    index_name = "korean_news"

    # 검색어
    search_query = "검색 엔진"

    # Elasticsearch 검색 API 호출
    res = es.search(
        index=index_name,
        query={
            "match": {
                "content": search_query
            }
        },
        size=5 # 상위 5개 결과만 가져오기
    )

    print(f"'{search_query}' 검색 결과 (상위 5개):")
    print("-" * 50)

    # 검색 결과 출력
    for hit in res['hits']['hits']:
        score = hit['_score'] # 이것이 BM25 점수입니다.
        title = hit['_source']['title']
        print(f"점수: {score:.2f}  |  제목: {title}")

    print("-" * 50)
    ```
    - 위 코드는 Kibana와 Python Client를 활용하여 검색 쿼리를 실행하고 결과를 출력하는 방법을 보여준다

  - BM25 모델의 작동 방식:
    - Elasticsearch의 기본 검색 모델로, 문서와 쿼리 간의 관련성을 점수화한다.
    - _score 필드에 계산된 BM25 점수가 저장된다.
  - Top-5 검색 결과 출력:
    - size 매개변수를 사용하여 원하는 개수의 결과를 가져온다.
    - 각 결과의 점수와 제목을 출력하여 관련성을 확인한다.
  - 검색 스코어 분석:
    - 출력된 점수를 기반으로 검색 결과의 관련성을 분석할 수 있다.
    - 예를 들어, 높은 점수를 가진 문서가 쿼리와 더 관련성이 높다고 판단된다.

      - 점수는 3.10에서 3.03까지 분포되어 있으며, 상위 문서와 하위 문서 간의 점수 차이가 크지 않다. 이는 검색 쿼리 "AI"가 포함된 문서가 많거나, 문서 간의 관련성 차이가 크지 않음을 나타낸다.
    - 검색 모델의 성능:
      - BM25는 단순히 키워드 매칭과 빈도수를 기반으로 점수를 계산한다. 따라서 문서의 맥락이나 의미를 고려하지 못할 수 있다.
      - 예를 들어, "AI"라는 키워드가 포함된 문서가 높은 점수를 받았지만, 문서의 구체적인 내용이 쿼리와 완전히 일치하지 않을 수 있다.
